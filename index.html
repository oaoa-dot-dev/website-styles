01. Design Tokens & Philosophy

The OAOA Neo-Brutalist Design System is engineered for high utility, maximum legible contrast, sharp 1px borders, hard 4px drop-shadows, zero corner-radii, and unified monospace typography.

Core Tokens (:root)

Token Variable Value Visual Reference Usage Purpose
--bg #ffffff Surface White Base page & card backgrounds
--bg-code / --bg-dark #0c0f14 / #000000 Deep Dark Console, logs, dark terminal blocks
--border #000000 Solid Black (1px) Standard borders on all boxes/inputs
--shadow 4px 4px 0 #000000 Hard Offset Hover states, modals, active focus
--font / --mono 'IBM Plex Mono', monospace Aa Bb 123 Unified monospace typography everywhere
--success #15803d Emerald Status OK, connected, verified
--warning #ca8a04 Amber Pending, queued, requires auth
--danger #b91c1c Crimson Errors, destructive actions, revoke
--info #0369a1 Sky Blue Informational badges & categories

Top horizontal tab bars (.tabs & .tab), segmented sub-page switchers, filter toolbars, and responsive headers form the primary navigation hierarchy.

Secondary Sub-Navigation Tabs (.tabs-secondary)

SUB-NAV // Overview Realtime Feed Filtering Rules Exports & CSV Audit Log
Two-Tier Stacked Navigation Hierarchy

Primary bar (pure white) stacked directly above the secondary sub-nav bar (shaded grey) with seamless 1px boundary:

Operations Intelligence Infrastructure Security
VIEW // Live Intercepts Threat Entities Geo-Mapping Raw Telemetry
Interactive Segmented Tabs & Content Panes

Click any tab below to switch live content panels via data-tab-target:

Tab 1: Interception Rules

Configure keywords, regular expressions, and channel inclusion filters for incoming message streams.

Tab 2: Translation Engine Settings

Select default model endpoints (Ollama native, OpenAI API, local llama.cpp) and target translation languages.

Tab 3: Storage Limits & Media

Set per-channel max file size thresholds (MB) and attachment retention policies.

14. Starter Template

Copy and paste this minimal boilerplate into any new web project to instantly inherit the full design system.

  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;700&family=Inter:wght@400;600;700;900&display=swap" rel="stylesheet">
